First release.

Papermill turns a PDF into a BOOX Notes notebook whose pages are the PDF's own shape, with
the PDF's links working. Newer versions of Notes (seen on 46343, firmware 4.3.1) store every
imported PDF page as A4, which shows a page made for the screen at 71% size.

- Choose a PDF, or open or share one to Papermill. **Make notebook** saves a `.note` file in
  `Download/Papermill`; **Open in Notes** hands it to Notes' own import screen.
- Pages are stored at the PDF page's shape and Notes' standard width, the same size older
  Notes stored, so pens are sized against the page as they are in a native notebook.
- The PDF is embedded unmodified. The file carries no account, library or device identifiers.

Tested on a Palma 3 (Notes 46343), Palma 2 Pro (Notes 45960) and Note Mini C (Notes 46258).
Not yet tested: rotated, cropped, landscape or mixed-size PDF pages.
